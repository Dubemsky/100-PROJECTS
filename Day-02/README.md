# Day 2 — Text to Speech

A web app that turns text into speech.

1. Type some text
2. Search for a language and pick a voice
3. Click Convert
4. Play or download the audio

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```

Then open [http://127.0.0.1:5001](http://127.0.0.1:5001) in your browser.
