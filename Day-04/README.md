# Day 4 — To Do List

A desktop to-do list app built with `customtkinter`, using a `tasks.json` file for storage.

1. Click "+ Add Task" to create a task with a name and a due date (picked from a built-in calendar)
2. Tasks show up in the Pending tab, colored red/yellow/green based on how soon they're due
3. Click a task to edit its name/date, mark it complete, or delete it
4. Completed tasks move to the Completed tab
5. The Pending tab shows a progress bar and task counts for both tabs

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```
