# Day 5 — QR Code Generator

A desktop QR code generator built with `customtkinter`.

1. Pick a mode — URL/Text or WiFi
2. For WiFi, enter the network name, password (with a show/hide toggle), and encryption type
3. Customize the QR code color and background color
4. Optionally choose a logo to embed in the center (with a clean white background behind it)
5. Click Generate, then Save as PNG to export it

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```
