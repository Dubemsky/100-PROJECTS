# Day 1 — Weather App

A simple desktop weather app built with `customtkinter`.

Type a city name and hit "Get Weather" to see the current temperature, "feels like" temperature, today's high/low, a weather icon, and sunrise/sunset times. The sidebar lets you find cities around the world that are currently sunny, rainy, windy, snowy, hot, or cold.

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```
