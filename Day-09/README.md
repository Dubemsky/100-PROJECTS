# Day 9 — Tic Tac Toe

A desktop tic-tac-toe game built with `customtkinter`, styled as a wooden box with procedurally generated wood-grain tiles (via Pillow) instead of the usual flat card look.

1. Click a tile to place the current player's mark, burned into the wood — the turn switches automatically
2. When someone wins, the winning tiles highlight gold and a red line draws across the row, column, or diagonal
3. A full board with no winner shows as a draw
4. Score (X wins / O wins / draws) tracks across rounds
5. Click New Game to clear the board for another round without resetting the score

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```
