# Day 13 — Table Tennis

A desktop table tennis (Pong-style) game built with `customtkinter` and a `tkinter` canvas for the real-time physics — paddle hits, wall bounces, a fading ball trail, and a simple AI opponent.

1. From the menu, choose Play vs Computer or Play vs Human
2. Move your paddle with W / S or the arrow keys — in Play vs Human, Player 1 uses W / S and Player 2 uses the arrow keys
3. Hit the ball past your opponent's paddle to score — first to 7 points wins
4. Press Space to pause, or use the in-game Pause/Menu buttons
5. When the match ends, Play Again replays the same mode, or go back to the Menu to switch modes

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```
