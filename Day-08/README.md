# Day 8 — Hangman

A desktop hangman game built with `customtkinter`, with a progressive drawing on a `tkinter` canvas.

1. Pick a category (Animals, Countries, Movies, Tech) from the tabs at the top
2. Click letters on the on-screen keyboard to guess — correct guesses reveal the letter everywhere it appears, wrong guesses cost a life and add to the hangman drawing
3. Win by revealing the whole word before 6 wrong guesses; lose and the word is revealed for you
4. Click Play Again to start a fresh round — your win streak (and best streak) carries over across rounds

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```
