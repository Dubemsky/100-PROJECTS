# 100 Projects

100 small programming projects, one at a time.

Each project lives in its own folder with its own `README.md` explaining what it does and how to run it.

## Setup

1. Create a virtual environment:
   ```
   python3 -m venv venv
   ```
2. Activate it:
   ```
   source venv/bin/activate
   ```
3. Install the requirements:
   ```
   pip install -r requirements.txt
   ```
