# Day 3 — Calculator

A desktop calculator built with `customtkinter`.

1. Type numbers using the number pad
2. Pick an operator (+, -, *, /)
3. Type the second number
4. Click = to see the result

Backspace (⌫) deletes the last digit you typed, and C clears everything.

## How to run

Make sure you've completed the [setup steps](../README.md#setup) in the root folder first, then:

```
python3 main.py
```
